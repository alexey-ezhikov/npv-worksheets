# Не просто выжить — рабочие материалы для ИИ-ассистентов

> **© 2026. Проприетарные учебные материалы курса «Не просто выжить». Правообладатель: ИП Ежиков Алексей Юрьевич.** Коммерческое переиспользование и создание или использование производных материалов для коммерческих целей запрещены. Разрешено личное некоммерческое учебное использование. Полные условия: [TERMS_OF_USE.md](TERMS_OF_USE.md).

Это публичный репозиторий, **не open source**. Материалы курса предназначены для системного анализа и разработки личной стратегии в неопределённости при помощи ChatGPT, Claude, Gemini, Kimi и других ассистентов.

## Начните здесь

1. Создайте отдельный проект «Не просто выжить» (в Gemini — Gem, если доступен).
2. Скопируйте содержимое [PROJECT_INSTRUCTIONS.md](PROJECT_INSTRUCTIONS.md) в поле инструкций проекта. Полный текст укладывается в 2000 символов.
3. Скачайте и загрузите два файла: [00_START_HERE.md](00_START_HERE.md) (общие правила) и [01_MY_MAP.md](01_MY_MAP.md) (пустая личная карта).
4. Открывайте отдельный чат для каждого исследования. Никакой «первой задачи», инициализации или обязательного порядка чатов нет.
5. Для заданий преподавателя подключайте соответствующий файл `TASK_*.md` и указанные в нём методики `METHOD_*.md` в проект или к чату.

Подробная памятка: [README_USER.md](README_USER.md).
