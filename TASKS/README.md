## Опубликованные задания

| Задание | Когда использовать | Требуемые методики |

| [После первого занятия](TASK_01_AFTER_CLASS_v1.md) | Рефлексия и подготовка к «Карта и территория» | Интервью и аудит; дневник по желанию |
| [Зарисовки и ловушки](TASK_SYSTEM_STORIES_v1.md) | Между занятиями, по интересу | Методика зарисовки **или** методика ловушки |

Начните новый чат внутри проекта и назовите нужное задание (например, `TASK_01_AFTER_CLASS_v1.md` или `TASK_02_CREDO_v1.md`). Приложите соответствующую методику и двигайтесь по одному вопросу, если её режим диалоговый. Не вставляйте сюда персональные ответы и заполненную личную карту: репозиторий публичный.
