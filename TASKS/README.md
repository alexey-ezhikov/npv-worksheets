# Учебные задания (`TASK_*.md`)

> **© 2026. Проприетарные учебные материалы курса «Не просто выжить». Правообладатель: ИП Ежиков Алексей Юрьевич.** Коммерческое переиспользование и коммерческие производные материалы запрещены. Полные условия: [TERMS_OF_USE.md](../TERMS_OF_USE.md).

При публикации занятия здесь появятся учебные задания с именами `TASK_<имя>_v1.md`. Каждый файл определяет исследовательский вопрос, этапы работы, ожидаемый результат и ссылки на обязательные методики. Точные имена методик указаны **в самом задании**.

**Сейчас задания не опубликованы.** Если файла здесь нет, не просите ИИ восстановить его по имени; запросите материал у преподавателя.

Использование: скачайте нужное задание и обязательные методики, добавьте их в проект/чат и напишите: «Выполни со мной `TASK_<имя>_v1.md`, следуй указанным методикам, работай по шагам».
